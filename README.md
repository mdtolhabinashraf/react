# @tolha/react

A collection of reusable utilities for TypeScript projects.

[![npm version](https://img.shields.io/npm/v/@tolha/react)](https://www.npmjs.com/package/@tolha/react)
[![License](https://img.shields.io/github/license/mdtolhabinashraf/react)](./LICENSE)

## Installation

Install the package using your preferred package manager.

**npm**

```bash
npm install @tolha/react
```

**pnpm**

```bash
pnpm add @tolha/react
```

**Yarn**

```bash
yarn add @tolha/react
```
