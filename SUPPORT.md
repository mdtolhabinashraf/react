# Support

For help with `@tolha/react`, use the appropriate channel.

- **Bug reports:** https://github.com/mdtolhabinashraf/react/issues
- **Feature requests:** Open a GitHub issue describing the use case.
- **Usage questions:** Check the README and API documentation first.
- **Security issues:** Follow [SECURITY.md](SECURITY.md).

When reporting a bug, include:

- The package version.
- Node.js, TypeScript, and package-manager versions, when relevant.
- Expected behavior and actual behavior.
- A minimal reproducible example.

Do not include passwords, access tokens, private keys, or other secrets.
